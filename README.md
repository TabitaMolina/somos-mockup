# Somos Multiespacio Curicó – Mockup

Prototipo estático (HTML, CSS, Bootstrap 5 y un poco de JavaScript) de una plataforma marketplace de bienestar.
Los datos son de ejemplo. Los valores "X" están por confirmar con Somos.

## Páginas
| Archivo | Pantalla |
|---|---|
| index.html | Buscador con filtros y resultados |
| perfil.html | Perfil del profesional con calendario |
| carrito.html | Carrito con desglose |
| pago.html | Pago |
| confirmado.html | Pago recibido |
| estado.html | Estado de la reserva |
| calificar.html | Calificación |
| admin.html | Panel de administración |

## Cómo verlo
Abre `index.html` en el navegador, o usa la extensión Live Server de VS Code.
